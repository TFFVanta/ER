# EXOTIC Codex Operator Foundation

This package implements milestone `EXOTIC-CODEX-001A`, the foundation for the EXOTIC Codex Operator, and extends it through the Prompt Compiler, Worker Runtime, and Session Engine milestones.

The package focuses on runtime bootstrap, configuration, structured logging, event bus integration, lifecycle orchestration, dependency injection, plugin registration, health monitoring, metrics, clean package startup and shutdown, deterministic prompt compilation, autonomous worker coordination, session lifecycle orchestration, verification/evidence management, governance approvals, policy automation, compliance auditing, and observability-backed forensic analysis.
