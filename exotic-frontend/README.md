# Exotic Command Center

A live React + Vite frontend for Exotic project management.

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints.

## Includes

- Live progress metrics
- Project cards
- Task execution board
- Milestones
- AI agent activity
- Build timeline
- Command palette
- White lab UI with thick black outlines and solid MINGO accents
