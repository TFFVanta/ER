# EXOTIC Unified App v0.6.1

Uses the exact uploaded ER logo for both the Windows desktop shortcut and the mobile app icon.

## Windows

1. Extract the ZIP.
2. Open the `windows` folder.
3. Double-click `Install-Desktop-Shortcut.cmd`.
4. Double-click the new EXOTIC desktop shortcut.

## Android

Run:

```bash
bash android/install-termux.sh
```

Then use Chrome → Install app / Add to Home screen.
