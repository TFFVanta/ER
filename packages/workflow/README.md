# @exotic/workflow

Dependency-aware workflow and production orchestration for EXOTIC.

The package provides a layered Production Fabric:

- deterministic dependency planning and cycle detection
- studio/lane swarms with optional challenger replicas
- bounded concurrent execution and retries
- approval and verification barriers
- mandatory evidence receipts before downstream work can run
- projection from the canonical venture workspace task graph

See [`../../docs/PRODUCTION_FABRIC.md`](../../docs/PRODUCTION_FABRIC.md) for the system contract and roadmap integration.
