EXOTIC PORTAL v1

1. Extract to C:\Projects\Exotic\Portal
2. Right-click Enable-Portal-Lan-Access.cmd and Run as administrator once.
3. Double-click Launch-Portal-Server.cmd.
4. Open the printed private URL on your phone while both devices use the same Wi-Fi.
5. In Chrome, choose Add to Home screen.

Features:
- Live PC/build status
- Configure, build, clean rebuild, run
- Open VS Code and output folder on the PC
- Live logs
- Browse and edit project text/code files
- Automatic .portal-backup before edits
- Optional ChatGPT button
- ER logo and MINGO retro pop-art mobile design
- Pairing-token authentication

Do not expose port 8765 directly to the public internet.
