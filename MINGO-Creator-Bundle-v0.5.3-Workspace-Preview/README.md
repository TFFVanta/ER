# MINGO Creator Bundle
## EXOTIC v0.5.3 Workspace Preview

This release upgrades Exotic Studio from a visual preview into a usable
local workspace.

## Start

- Double-click `Launch-Workspace-Preview.cmd`
- Or open `Launch-Studio-Preview.cmd`

## Workspace capabilities

- Create and delete projects
- Create, complete, and delete tasks
- Automatic project progress calculation
- Persistent local browser storage
- Import workspace JSON
- Export workspace JSON
- Reset to the included default workspace
- Command palette with Ctrl+K
- Native `exotic.exe platform` bridge

## Native runtime

Copy your compiled executable to:

`app\bin\exotic.exe`

Then use the main launcher and choose **Run Platform Services**.

Developer preview only. Not a signed production release.
