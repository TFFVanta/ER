# Exotic SDK Core

Starter implementation of the Exotic SDK foundation:

- Universal Object Model
- Universal State Model
- Live Metadata Fabric
- Universal Memory Graph
- Event Bus
- Protection Gate
- Index Manager
- Core Engine subscriptions

## Run

```bash
npm install
npm run dev
```

## Core loop

```txt
Observe → Metadata → Protect → Index → Graph → Memory → Engines → Learn
```
